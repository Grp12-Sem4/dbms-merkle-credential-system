Overview

Verify identity, institutional claims, and record integrity from one controlled workflow.

This interface connects the Flask verification service to MySQL-backed academic credentials, consent checks, and Merkle-based integrity validation. Start with identity claims, move through institutional data, and finish with the cryptographic integrity proof.

Claim Validation Workbench

Step 1

Identity Checks

Full Name

Matches the claimed student name against the protected base identity record.

Date of Birth

Confirms the claimed birth date using the canonical student identity table.

Step 2

Institutional Context

Institution Name

Confirms which institution issued the stored academic credential.

Department

Verifies the department attached to the student's institutional credential.

Step 3

Academic Status Checks

Graduation Status

Checks whether the student is currently pursuing, graduated, or in another tracked state.

GPA

Validates a claimed GPA only after consent and integrity checks pass.

Step 4

Supporting Personal Check

City

Checks whether the submitted city matches the protected student personal credential.

Step 5

Integrity Proof

Confirms the stored Merkle root matches recomputed credential leaves for the selected student.
